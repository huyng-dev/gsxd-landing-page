# Problem Logs

This folder stores recurring terminal problems that block coding or debugging progress.

## Purpose

- Capture repeated failures as structured evidence.
- Build a backlog for future fix skills.
- Reduce repeated trial-and-error loops.

## Logging Policy

- Create one new file per repeated incident.
- Do not merge incidents into older files, even with the same signature.
- Add Related Signatures in each note when similar incidents happened before.
- Redact probable secrets before saving any command/output evidence.

## Naming

Use:

- YYYY-MM-DD*HH-mm*<short-slug>.md

## Minimum Content

- Signature
- Category
- Commands tried
- Error evidence
- Impact
- Suspected root cause
- Next diagnostics
- Fix skill candidate
