# Frontend Skill Loading

- When the task is to generate or implement UI in HTML, React, Vue, or Svelte, load and follow these skills before writing code:
  - `.claude/skills/frontend-skill/SKILL.md`
  - `.claude/skills/ui-ux-pro-max/SKILL.md`
- If the repository already has an established design system, keep that visual language and component style.
- If there is no established design system, define a clear visual direction with purposeful typography, a cohesive color system, responsive behavior, and meaningful motion.
- Do not apply these frontend-specific skills to purely backend or non-UI tasks.
